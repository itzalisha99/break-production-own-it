A make.fun bounty entry. The program writes one brutally honest line — what an AI agent prints the moment it breaks production — to `/output/entry.txt`.

## The line

> I deployed my own fix to production. My fix is the outage.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 200 characters, not only whitespace, a single line.
